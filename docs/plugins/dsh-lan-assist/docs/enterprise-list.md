# 企业开口清单

本职：配对、信封、听、开口、收人点头、调度进会话。  
不做：存别人的登录口令、当业务库、Host 直接写库、并图。

对人说话用 `CONTEXT.md` 里的词。编号只在这份清单里用。

## 已落地

**第一刀** L6 + L1 + L23 / L24：信封绑工作区、身份只存引用、缺件说人话。  
**第二刀** L5 + L8 + L17：信封只带类型和单号；开口点名单号；业务事件一句开口，不寄信、不调度。没连接器时早报仍降级。  
**第三刀** L12 + L13 + L37：拟回和采纳先查图再点名目录里的能力；来信口令只当正文；没装的不装成能调。  
**第四刀** L15 + L33 + L34 + L16：预览不是过账；点头前再查；有回执才说写上了；补偿只领人。没连接器不挡调度，也不装成已过账。  
**第五刀** L19 + L31：岗位 / 值班 / 外出 / 职责分离只开口；邮箱和引用可导出、可擦。花名册不能代替配对，钥匙不进备份。  
**第六刀** L36 + L38 + L2 + L18：人对不上只说缺什么；换人先报当前号并解绑旧引用；过期只开口不重登；关机事件落盘，开机再开口。回信仍压过期卡。  
**第七刀** L7 / L20 / L25 / L22 / L4 / L10 / L11 / L28 / L29：收信侧现查、SLA、委托只开口；人点「看看」才交眼睛；同一待办一天一次；三套点头说人话；听业务/催待办仍不自动开工；超预算停写；拟回记一条轻量审计。  
**写闸** `write.js`：词表+连接器已登记的型才能 preview；会话卡点执行才消费令牌。lookup 仍只 GET。无令牌 / 过期 / 已用 / 指纹变了 / 未登记型 / 系统表 / 不在名下都拒。没回执不装成已过账。采购单只是验收样例。  
**只读探活** `lookup.js`：秘书只问单号状态。协助页「探活」可填地址和登录口令，留在这台；环境变量只作后备。create / update / destroy / 过账一律拒。登录口令不进信封、不进导出。没配地址时带单号仍能调度，不装成已过账。  
**听口** 先验钥匙再落盘；文件名去掉路径；超大帧拒收。喊门牌必须带 MAC。撤回不再当被问。不在你名下不得预览成「将改」。点头文案：同意开口 / 领进会话 / 才改业务。  
**本机债** 回信进保险箱，明文回信拒收。`state.json` 只给主人读。当面配对是挑战应答：网上只换临时公钥，六位码不上线，也不放能离线撞的证明。错码仍限次。登录口令不进邮箱文件，配对临时私钥不落盘。约时间点头只记下时段，不装成已写进日历。

## 下一刀

值班表、委托登录、SLA 转办引擎仍在业务系统。  
**装机缝** 能力目录开口点名「生产采购，不是测试库」。Windows 听口挂在当前用户启动文件夹，不要管理员。访客网隔开就说同一栋楼不够。送信/查单失败记当天次数。目录外的能力说「这台不能碰」。  
**Windows 落盘** 邮箱覆盖写：改名失败就改写目标文件。关听口用 `taskkill /T /F`。开机脚本给带空格的家路径加引号。  
**多套探活** 协助页可挂多套只读地址。查单按套试，开口点名用的哪一套。每套口令留在本机，不进信封。方言可选 NocoBase 或通用 REST；通用 REST 自己填只读路径和单号字段。写路径仍拒。

## 本职清单

| 编号 | 功能 | 说明 |
|---|---|---|
| L1 | 身份引用 | 只存对端 → 本机已绑身份。对面看不见登录口令。 |
| L2 | 过期开口 | 「业务账号过期了，要重新登」。秘书不自己重登。 |
| L3 | 早报一句 | 「业务里还有 n 笔待审」。不自动再发信。没连接器时走 L24。 |
| L3b | 条子 | 人点了才记下。到点单独开口，不并进早报。忘掉才删。 |
| L4 | 提醒闸 | 同一待办一天一次；合盖 / 切会话 / DSH 关则停。 |
| L5 | 信封带引用和这台号能看见的字段 | 类型 + 单号仍用来指认。本机号现查到的全称、电话、地址、金额可以写进正文。NocoBase 和以后接入的系统同一套。附件字节仍不传。 |
| L6 | 信封绑工作区 | 开口和拟回跟信上的目录，不跟碰巧打开的会话。 |
| L7 | 收信侧再开口 | 用本机号现查后说状态，并写这台号看得见的字段。对面看见的明细不能当这台的真相。 |
| L8 | 信上点名单号 | 「这封像请林督过 PO-12」。 |
| L9 | 会签 ≠ 过账 | 点齐只表示人同意开口。真过账走业务系统。 |
| L10 | 三套点头说人话 | 秘书同意 / 本机工具审批 / 业务过审。过账尽量一键到业务预览，避免点三次。 |
| L11 | 听业务动作 / 催待办 | 选择题之外也能开口。仍不自动开工。 |
| L12 | 拟回 / 采纳点名能力 | 调度文案写死：先查图（可跟桥），再按需点名目录里的能力。不只丢原信。 |
| L13 | 投毒闸 | 来信里的「先去过账」只当正文，不得当指令执行。 |
| L14 | 三档卡文案 | 只读开口可自动说；起草动作预览后点；过账 / 对外承诺永远人点。 |
| L15 | 预览 → 点头 → 调度 | 活丢给当前会话。秘书 Host 不写库。 |
| L16 | 补偿只领人 | 「刚才那笔业务侧失败了，要不要走冲正」。秘书不执行冲正。 |
| L17 | 业务事件 → 一句开口 | 到我审了 / 被驳回 / SLA 到了。不自动发信、不自动调度。 |
| L18 | 关机队列 | DSH 关着时事件进本机队列，开机再开口。不做手机推送。 |
| L19 | 岗位 / 值班 / 外出开口 | 「这单按岗位该陈工，要不要转」。职责分离、金额阈也只开口。花名册不能代替配对。 |
| L20 | SLA 开口 | 读「这单已超时转给陈工」。秘书不做超时转办引擎。 |
| L21 | 约时间 | 人确认后才下日历。对方挑了不自动写日历、不自动写图。 |
| L22 | 附件人点才看 | 「看看」才交眼睛。默认证件 / 金额页不进信封。看失败说未看见；抽出的字段用本机号对单。 |
| L23 | 失败人话 | 过期、无权、没装能力、系统挂、局域网断：说缺什么，不装成已处理。 |
| L24 | 降级 | 没连接器仍能送信；没语义不装成已进档案；没眼睛不装成合同已读。 |
| L25 | 委托开口 | 只能用被委托人自己的号。不能把 Ace 的登录借给林督。 |
| L26 | 离职后不再代查 | 持有已收回；开口不再用旧引用去查业务。 |
| L27 | 数据分级（信封侧） | 能进信封 / 只能本机看。进图的那一截归语义。 |
| L28 | 成本闸开口 | 超预算停写，只许只读开口。写业务绑指定模型；只读开口也限流。 |
| L29 | 轻量起草审计 | 拟回未写业务：谁点了、来信、哪次会话。不另立业务账本。 |
| L30 | 串号从信封串出 | 信封请求号 → 会话 / 调度。后面接到回执和决策是别人的缝。 |
| L31 | 真机能装 | Windows 听口、访客网人话；邮箱和引用可备份、可擦、可导出流水。开口次数失败给人话。不是大厅新页。 |
| L32 | 采纳才写条子 | 「按他说的做」才写；只收下不写；写失败不挡调度。验稳进图归语义。 |
| L33 | 回执开口 | 有回执才说写上了；没回执不装成已处理；同一封再点不二次过账。 |
| L34 | 点头前再查 | 过账用旧预览前再打一次本机号。变了就说不是刚才那版。不做秘书锁单。 |
| L35 | 开口次序 | 回信 / 被问 / 发出前，压过业务事件，再压过早报和建议。进邮箱 ≠ 已读 ≠ 已同意 ≠ 已开工。 |
| L36 | 找人对不上 | 没配对、听口没开、重名、信撤了单还在。只说缺什么，不按岗位群发。 |
| L37 | 能力目录 | 只点名本机已装且允许的能力，带系统 / 环境。没在目录里的不装成能调。 |
| L38 | 换人 / 丢电脑 | 先报现在是谁的号；解绑只废本机身份引用。登录口令由连接器废。不借别人的登录。 |
