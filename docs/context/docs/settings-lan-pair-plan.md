# 设置里局域网配对：怎么拿掉

对照 [设置里局域网配对能不能拿掉](settings-lan-pair.md)。

权威是 IM 添加同事那一条配对。设置里这块是同一条路的重复壳。拿掉壳，不要拿掉配对。

## 1. 删的

设置「运行环境」里「局域网配对」整块：开码、门牌列表、填码、本机自测那套说明。人不再从设置走进同一条配对。

## 2. 改的

还写「打开设置配对」「去运行环境配对」的入口，改到 IM 添加同事。规格里若还要求设置有配对表单，改成 IM 是入口。不要留死链。

## 3. 不动的

`imPairMint` / Handshake / Accept / Reject、lan-assist 状态、已配对的人、`--peer`、门牌本身。现查、改行、过账、重载核心不碰。

## 你怎么验

设置运行环境不再出现局域网配对。IM 添加同事仍能开码、填码、看到已有对端。点旧文案不会进设置空页。已配对的人还在。
