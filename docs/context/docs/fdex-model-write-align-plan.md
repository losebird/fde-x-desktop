# 模型写入对齐官方：怎么收

对照 [哪些 DSH 能力该接到工作台](fdex-dsh-features-fit.md)、[FDE-X 和 DSH 模型还差哪几条](fdex-dsh-parity-gaps.md)、[硅基 Qwen 400 是怎么回事](siliio-qwen-400.md)。点头后按此落地。

家目录不换。还是工作台自己那一份。

权威是官方这条模型有没有推理档。有就写，没有就不写。不要自定义提供方默认 `reasoning: true`。不要写死硅基、grok、deepseek 名字。

## 1. 推理档

新加、discover、保存：只有官方目录/schema/discover 明确带推理档才写入 `reasoningEfforts`。没有就不写。

盘上被默认灌上、官方同模型没有的，拿掉。官方有的（grok / DeepSeek 等）不要动。

发出去的角色：没有推理档时不得发 `developer`。Off 不能仍发 `developer`。改转换层或配置，不要只改开关文案。

## 2. 密钥和获取模型

能清除密钥。获取可用模型只添加所选，禁止默认全选灌进配置。

保存走路径级，不要旧接口整段盖 profile。旧的默认灌推理、整段覆盖、用完的薄行/双轨，能删就删。

## 3. 不动

会话选模型那一层。现查、改行、过账。已经能用的 grok 密钥和推理档。官方整页不嵌。

## 你怎么验

硅基 Qwen 新开会话「你好」能回，选模型没有误灌的推理档。grok / DeepSeek 该有档位还在。清密钥后标签变缺失。获取模型只加勾的。家目录仍是工作台那份。
