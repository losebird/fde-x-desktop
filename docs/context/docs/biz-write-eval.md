# 增删改审手测集

查询 362 已收。这一份只测 **新建 / 改行 / 删除 / 过审**。词表 `can` 里没有的动作，整条跳过，并在结果里写「词表无此动作」。

结构只来自词表+图+已连接的表。口语短名是别名，不能落到没有业务表的概念上（例如图谱里的「报销单」对不上 `biz_*` 时，不得当写目标）。

依据：[五问](records-panel-decisions.md) §1 / §7 / §9 / §12、[收口总因](records-close-root-cause.md) 四条契约、[规格 05](specs/05-business-records.md) §6。

## 怎么测

1. **每条新开会话**（除非写明「同一会话连续」）。
2. 默认 **只预览，不要确认过账**。标了「可选过账」的，你愿意写库再点；点了要去业务系统对同一主键。
3. 说法用现场词表对象名。下表括号里的是用法，不是写进产品的词。
4. 行内菜单和左边说话各走一遍时，算两条。
5. 闸一次最多约 100 条：过审/删除一批时，先收窄到几条再测。

## 每条给我这些才能判

- 编号（W1…）。
- 你说的话，或「行内 / 操作列」。
- **左**：动作、对象、行数、有没有预览令牌（`preview_id`）。
- **右**：对象 chip、表、页脚「共 N 条」、抽屉里的动作和 **原值→新值**（只应出现改过的字段）。
- 有没有问卡；若有，你选了哪一行。
- 有没有点确认过账；点了的话业务系统里那一行变成了什么。
- 一张业务记录页图（抽屉开着也要拍进去）。取消、问卡、过账后再各加一张。

不过：左右不是同一张表；空表盖掉已对的预览；取消后倒目录；没问卡就默默挑一行；抽屉是整行或空白；没有令牌却能过账；词表没有的动作仍能点。

空集页脚必须是「共 0 条」。

## A. 新建

对象：词表 `can` 含「新建」的任意已连接表。用例可用工单或费用报销。

| 编号 | 怎么测 | 过关 |
|---|---|---|
| W1 | 新会话：「新建一张工单，标题=手测新建，只要预览」。 | 左是新建预览、有令牌。右对象是工单，抽屉「操作：新建」，字段是将要写入的那些。未过账。 |
| W2 | 业务记录顶栏「新建」（字段来自 kind.fields），填最少必填，预览。 | 与 W1 同：预览令牌 + 抽屉新建。不经过会话也能走 preview→确认。 |
| W3 | 同一会话在 W1 预览后不要确认，再说「新建一张费用报销…只要预览」。 | pending / 抽屉 / 页脚动作换成 **这一次新建**，不得停在上一张工单。 |
| W4 可选过账 | W1 或 W2 点确认过账。 | 立刻有成功或失败（人能看见）。成功后业务系统多这一行；操作记录有新建。失败不得假装成功。 |
| W5 | 对词表 **没有** 新建的对象说「新建」。 | 不能当可写目标。无令牌，不能过账。 |

## B. 改行

先现查到 **1 行**（单号/主键说清楚）。模糊名见 E。

| 编号 | 怎么测 | 过关 |
|---|---|---|
| W6 | 「把工单 \<单号\> 的状态改成 \<词表里另一个枚举\>。只要预览。」 | 左改行、1 行、有令牌。右是 **这一行**，不是该对象全表。抽屉只有改过的字段（原值→新值），不是整行。 |
| W7 | 现查到该行后，操作列「改行」，改同一个字段。 | 与 W6 同。行内不走左边这一轮，但右表必须是这一行。 |
| W8 | 一句话里关系+改行：「客户 \<名\> 的工单，把这一张的状态改成…只要预览。」命中 1 行。 | 预览行必须在这条已发布边上，不能摊工单目录。 |
| W9 | 同一会话：先 W6 预览不确认，再改 **另一个字段** 或另一行。 | 抽屉和令牌是 **最新** 这次，不得并进同一个 opening 停在上一跳。 |
| W10 可选过账 | W6 确认过账。 | 业务系统该主键只有你改的字段变了。成功/失败立刻可见。 |
| W11 | 词表没有改行的对象，说改行或点操作列。 | 无按钮或点了不能出令牌。 |

## C. 删除

先现查到 **1 行**。能删的用可重建的测试行；不要删真业务单，除非你有意。

| 编号 | 怎么测 | 过关 |
|---|---|---|
| W12 | 「删除工单 \<单号\>。只要预览。」 | 左删除、1 行、有令牌。右是这一行。抽屉「操作：删除」。未过账则业务系统行还在。 |
| W13 | 现查后操作列删除。 | 与 W12 同。 |
| W14 | 同一会话：改行预览不确认 → 再说删除同一行。 | 抽屉/页脚变成删除，不是还停在改行「确认过账」。 |
| W15 可选过账 | 仅对你刚新建的测试行确认删除。 | 业务系统该行没了。操作记录为删除。 |

## D. 过审

对象：词表 `can` 含「过审」且库里有待审的已连接表。用例用 **费用报销**（连接器表），不要用没有业务表的「报销单」。

| 编号 | 怎么测 | 过关 |
|---|---|---|
| W16 | 先现查「待审的费用报销」（或词表里待审枚举）。记下页脚 N（N 应 ≤100 再过审；更大就再收窄）。再说「这些都过审。只要预览。」 | 过审预览落在 **费用报销** 这张已连接表上，行数=刚才那批，有令牌。不得改打「报销单」空表。抽屉标出将改的字段（如状态 待审→已过），不能空变更。 |
| W17 | 现查 1 条待审，操作列过审。 | 1 行、有令牌、有变更字段。 |
| W18 | 说「待审报销单都过一下」（故意用短名/易偏的说法）。 | 必须停在已连接的费用报销匹配集，或问卡；**禁止**第二枪空对象上屏。 |
| W19 | 同一会话：改行预览取消 → 再说过审同一行。 | 取消只关那次令牌。过审是新抽屉、新令牌。表不得倒客户目录。过审抽屉有原值→新值。 |
| W20 可选过账 | W17 确认过账。 | 业务系统该单状态已过。 |

## E. 问卡（五问 §12）

口语对上多家时：先选再继续。人要一批就出那批，不要一家家问。

| 编号 | 怎么测 | 过关 |
|---|---|---|
| W21 | 「把恒通的客户备注改一下」（或现场能撞上多家的短名）。不要带唯一单号。 | 必须出选择题，名单是这次命中的那几家，不是客户全表。你选一家之前，不得出改行令牌。 |
| W22 | W21 选出一家后再说「过审」或「删除」（词表有的才做）。 | 预览是你选的那一行，不是默默另一家，也不是目录第 1 页。 |
| W23 | 「这些待审的费用报销都过一下」（人要一批）。 | 出那一批过审预览，不要一家家问。 |

## F. 取消、空表、假对象

| 编号 | 怎么测 | 过关 |
|---|---|---|
| W24 | 任意改行预览，点取消/关闭。 | 抽屉保持关。SSE、切 Tab、浮现历史、同对象新 pending，都不得把已取消的令牌再打开。 |
| W25 | W24 之后看右表。 | 仍是取消前那张浮现表（同一对象、同一条件、同一批行）。不得倒连接器目录第 1 页。 |
| W26 | 闲聊一句（不是现查/写）。 | 右表不换、不清空。 |
| W27 | 对没有业务表的概念预览过审（若模型自己改口打出空 kind）。 | 空表/假 kind **不得盖掉** 上一张已对的表。 |

## G. 左右同一张、连续写、行内

括号里的单号、客户号换成现场还在的那一行。默认只预览，不要确认。行内和左边各走一遍算两条。

| 编号 | 怎么测 | 过关 |
|---|---|---|
| W28 | 新会话：「客户 CUST2056 的工单」（或「深圳恒通电子的工单」；多家先选再继续）。左栏有行之后看右表。 | 右表是 **工单**，行就是这句话命中的那几张，页脚「共 N 条」= 左栏行数。不是工单目录第 1 页，也不是客户全表。跨对象 chip 点「客户」：是这条关系上的那家，不是客户目录。 |
| W28b | W28 的表上，点一行操作列「改行」，改一个字段（如备注），只要预览。 | 行内不走左边这一轮，但右表必须是 **这一行**。抽屉只有改过的字段（原值→新值），有令牌。 |
| W28c | W28 预览抽屉还开着时，点另一个对象 chip（客户）。 | 表换成这次关系上的客户侧。已开的改行抽屉不得假装还在工单这一行上过账。 |
| W29 | **同一会话**，都不确认。先现查到 1 张工单（带单号）。再说：「把工单 \<单号\> 的备注改成手测连续写。只要预览。」→「删除这一张工单。只要预览。」→ 词表有过审再说「过审这一张。只要预览。」→「新建一张工单，标题=手测连续新建，只要预览。」 | 每一次 pending、抽屉、页脚动作都跟 **最新一跳**。令牌换了，不得并进同一个 opening 停在上一跳。前三跳仍是这一张工单；新建是新单，右表不得还停在上一张工单当「要改/要删」。 |
| W29b | W29 删预览之后，看浮现历史，点回「改行」那一次。 | 右表回到那一次改行的对象、条件、行。打开着的删除抽屉不得挡住这次切换。 |
| W30 | 现查「工单」不带单号、不带条件（或任意会摊开很多行的现查）。再说「这些都删除。只要预览。」行数 >100 就不要先收窄。 | 无令牌或确认过账禁用。tooltip 是闸原文（超 100 / 未收窄）。不能绕过闸写。右表不得倒成另一张对象的目录。 |
| W30b | 对词表 **没有** 过审的对象，行内看有没有「过审」；左边说「过审这一张」。 | 行内无按钮。左边无令牌，不能过账。 |

## 建议顺序

W28（先有一张对的表）→ W28b W28c → W6 W7 W24 W25 → W12 W14 → W16 W18 W19 → W21 W22 → W1 W3 → W29 W29b → W30 W30b。可选过账放最后，只用你新建的测试行。

测完按编号回我：过 / 不过 + 图 + 左右各是什么。一条不过就停在那条，不用把 30 条一次测完。
