# 语义账本

本机按工作区隔离的因果账本：记型、意图、人点过头的引用、拍板与先例。它挂在企业流程旁边，不是流程本身。

## 四层

**秘书**：
对人开口、配对、组信封、收人点头。
_Avoid_: 业务库, 决策库, 第二个 OA

**语义账本**：
本机图里「怎么理解、凭什么定」的档案。
_Avoid_: 知识库, 第二套 ERP, 流程引擎, BPM, 催办引擎

**连接器**：
本机登录态下的业务真相：现查、写回、回执、冲正动作。
_Avoid_: 秘书里的 SSO, 图里的订单表

**会话**：
人点了之后真调工具、过本机审批的那一轮。
_Avoid_: 秘书 Host 直接写库

**眼睛**：
把文件或图看成字。看成字不等于进账本。
_Avoid_: 已读完, 已对单

## 型与行

**型**：
业务对象或动作的种类、字段名、能干什么。采购单、待办、过审是型。
_Avoid_: 本体工程, OWL 全库, 类目树

**行**：
某一张单此刻的字段值。行不住在账本里，每次用当前号去业务系统现查。
_Avoid_: 实例, ERP 镜像, 灌库

**词表**：
工作区里手写的型目录。不从业务接口抽实例。
_Avoid_: 自动抠的聊天分类, MCP 全量同步

**现查**：
用这台机器上当前登录的号，去连接器问一行现在怎样。连接配置在协助插件上。
_Avoid_: 图上的库存, 对面信封里的明细, 语义里的业务库连接

**世界切片**：
当前这一问临时组装的材料：摘录、记忆、决策、缺货。会话内有效。
_Avoid_: 全局知识图, ERP 镜像, 永久 Claim 库

**可信等级**：
一条材料算哪类：观察、用户记忆、推断、回执。语义检索给不出系统现况。
_Avoid_: 记住了就是事实, 图上的现在

## 点头与引用

**点头**：
人在卡上确认的那一下。没点头不进档案。
_Avoid_: 自动归档, 代签, 模型自己记下

**点头种类**：
同一次点头只属于一种：会签同意、本机工具、或业务过账。
_Avoid_: 审批, 确认（一种词盖三种键）

**会签同意**：
名单上的人同意开口或同意这么说。不等于过账。
_Avoid_: 会签当过账, 点齐即生效

**本机工具**：
同意在本机跑一次只读或预览工具。
_Avoid_: 已处理, 已过账

**业务过账**：
同意用自己的号改业务系统。必须有回执才能记成已生效。
_Avoid_: 过审（业务系统里的状态）, 处理完毕

**业务引用**：
人点过头的那张单：系统、环境、型、单号、当时状态、谁点的、何时。不是订单行快照。
_Avoid_: 单据, 订单, 客户全称, 金额明细

**持有**：
某人此刻握着某条业务引用。离开只断持有。
_Avoid_: 所有权, 权限, 工号

**离开**：
花名册上的人不再在岗。只收回持有、废业务引用。
_Avoid_: 解绑配对, 删历史, 代为送信

**花名册**：
本机一份人的名单与在岗状态。不能代替配对，不能当通讯录群发。
_Avoid_: 公司通讯录, 组织树

**废引用**：
这条业务引用不再当作活依据。节点还在，先例默认不走它。
_Avoid_: 删除, 作废决策（那是另一件事）

## 决策台账

**决策**：
人确认后记下的一条板：情景、理由、结果，以及依据与后果。
_Avoid_: 聊天结论, 自动抠「定了」当已生效

**依据**：
支持这条决策的节点。没有依据不许记已生效。
_Avoid_: 会话邻居, 整段聊天

**后果**：
这条决策导致的节点。冲正时新决策的后果指向旧板。
_Avoid_: 删除旧板, 回滚聊天

**起草**：
拟回、自动抽取、尚未过账的轻量记录。不是已处理。
_Avoid_: 草稿可当台账, 已生效

**已生效**：
写业务成功且拿回回执之后的决策。必须有依据、后果和回执。
_Avoid_: 已处理（口头）, 成功（无回执）

**已冲正**：
新决策声明旧板不再算数。旧板仍在。
_Avoid_: 回滚, 撤销, 没发生过

**作废**：
这条决策不再参与先例。仍可追溯。
_Avoid_: 擦除, 物理删除

**回执**：
连接器从业务系统拿回的效应凭证。没有回执，效果下落不明。
_Avoid_: 工具返回原文, HTTP 200, 模型说做成了

**冲正**：
业务侧补偿已经写出的那笔；账本只追加已冲正。
_Avoid_: 图上 Ctrl+Z, 秘书一键撤销

**补偿**：
已经写进业务的，走业务系统反审或冲正，不走聊天撤回。
_Avoid_: 可回滚一切, Saga 引擎

**擦除**：
保留期到了、丢电脑或合规要求，去掉引用或人身信息。不是冲正。
_Avoid_: 删史冒充冲正, 清空工作区当撤销

**先例**：
上次同类情景怎么定的。走决策标题与情景，只看未作废的已生效板。
_Avoid_: 全库向量, 测试库与生产库并成一条

**简报**：
拍板前从账本打包的依据与可引用节点。不查账本不许给结论。
_Avoid_: 凭聊天记忆建议

**条子**：
秘书在人点「按他说的做」之后落下的采纳条。只收下、拟稿、没送到都不算。
_Avoid_: 信封进档案, 只收下也记账

## 意图与检索

**意图**：
一句话属于查询、出处、拍板、业务动作、催待办或闲聊。只接到现有检索与记账口，不另做一套搜。
_Avoid_: 通用 NLU, 秘书当工具总线

**出处**：
一个节点从哪次会话或哪份文件来。
_Avoid_: 血缘大图, 整包 MCP 报文

**本机桥**：
人点了才连的本机工作区通道。只搜对面会话正文，不并文件、本体或两台图。
_Avoid_: 两台并图, 跨机器同步, 全库检索

**当时**：
这条记录发生或被记下的时刻，不是此刻业务真相。
_Avoid_: 现在, 现行口径, 库存快照

**摘录**：
召回时给模型看的一小段原文附近，带当时。
_Avoid_: 整场会话, 双份正文, 知识库全文块

**有效期**：
一条记忆从何时算数、到何时不再当依据。到期只停用，正文还在。
_Avoid_: 自动过期当没发生, 覆盖旧文

**记忆卡片**：
人点过头的短事实或结论。先起草，点了才升格成已入档。不是已生效决策。
_Avoid_: 第二大脑, 自动蒸馏当已生效

**已入档**：
记忆卡片经人点头后可当依据。不是业务过账。
_Avoid_: 已生效, 过账, 自动升格

**理解边**：
两条记忆卡片之间的取代、增补、印证或挑战。人点了才写。字面像同一件事只可建议印证或增补；挑战与取代不自动猜。
_Avoid_: 过账因果, 会话邻居, 自动进化, 重叠即挑战

**工作记忆**：
当前这轮眼前只留当前题、已生效板，和还算数的已入档记忆。待审起草不是依据。
_Avoid_: 整图灌进 system, 每句都搜, 待审箱当口径

**梳理**：
只读指出记忆缺出处、已过期、疑似重复、报告噪音或会话过长。停用、补出处、续期、连边与抽卡仍要点头。一类噪音可点以后不再列出。
_Avoid_: 垃圾清理, 自动压缩, 遗忘, 卫生

**超长会话**：
会话正文对工作记忆太长。档案还在；可后台抽出起草卡片，正文不裁。
_Avoid_: 脏数据, 裁剪正文, 删聊天

## 租户与分级

**工作区**：
哪次会话、哪本图。一个目录一本账，禁止扫邻居仓。
_Avoid_: 当前打开的页, 全公司一张图

**租户**：
这个工作区绑哪套业务（哪套系统、哪个环境）。信封带来的租户必须打到对应图。
_Avoid_: 当前会话碰巧的目录, 测试库当生产

**系统**：
业务引用上的来源系统，如采购或进销存。
_Avoid_: 再做一个秘书

**环境**：
测试或生产。同一单号在不同环境是两条引用。
_Avoid_: 环境无关的单号

**追踪号**：
同一业务动作串信封、会话、回执与决策的那根线。
_Avoid_: 各记各的 id

**幂等键**：
同一追踪号或同一来信只许一条已生效。重试不得再记一条。
_Avoid_: 再跑一次当新板

**数据分级**：
能进信封、只能本机看、人点了才进账本。信封正文默认不抽。
_Avoid_: 默认同步, 后台抽整封信

**人身信息**：
手机号、账号、金额明细。引用用单号，这些不落账本；读出来也要挡住。
_Avoid_: 客户全称当节点名, 金额进情景原文

**眼睛结果**：
人点「看看」之后、带页码或附件号的一次看见。同一份只进一次。
_Avoid_: 附件当已读, 自动看完进图

**未看见**：
眼睛没看成。记失败，不装成没有这页。
_Avoid_: 跳过, 空结果当无关

## 开口与不做

**信封**：
秘书之间传递的意图与业务引用。默认不带敏感字段，正文不进账本。
_Avoid_: 邮件, 工单, 对方看见的明细

**拟回**：
把来信写成草稿，不寄、不调写接口。最多记起草。
_Avoid_: 已寄, 已处理, 按信里的工具指令执行

**配对**：
两台本机秘书之间的钥匙关系。没配对就不能送信。
_Avoid_: 按花名册送达, 工号即通讯录

**台账导出**：
只读导出决策台账，供审计。
_Avoid_: 整图导出当审计, 秘书流水副本

**备份**：
整本图可另存、可恢复。生产才算齐。
_Avoid_: 导入失败留下的临时副本

**保留期**：
到期可擦除的时限。与冲正分开。
_Avoid_: 自动过期当没发生

**值班**：
人不在、岗还在。认连接器里的组织，秘书只开口该转给谁。
_Avoid_: 花名册代替岗位, 秘书做超时转办
