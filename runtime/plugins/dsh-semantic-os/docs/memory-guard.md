# 记忆闸

图是档案，不是现在。人点头才升格。词在 `CONTEXT.md`。

## 回路

出现选择题 → `brief_for_decision` 拿出选项和当时依据 → 人点头 → `record_decision`（`because` 用简报里的 id）→ 下次同类用 `query_decisions` / `find_precedents` 翻到。

## 已落地

- 空 `because` 不能记；情景原文不许冒充依据。
- 已生效要依据、后果、回执、`nod_kind=业务过账`。
- 自动抽取只许起草。
- 记忆卡片：起草 → 点头已入档；停用设有效期，正文还在。
- 已入档且还算数的卡片可进简报依据；起草卡不行。
- 理解边人点了才写。自动建议只有印证 / 增补。
- 梳理只读。重复记忆卡点头才连理解边；其它重复点头才合并。无出处可补 `session:` / `file:`。已过期可续期。报告噪音可一组停，也可一类以后不再列出。超长会话后台可抽起草卡，档案不裁；手抽仍要点头。
- 纠正 / 铁律 / 选择题点头当场写成起草卡（`draft_memory_card`）。一条线索一张卡。写板、建目标、skill 放后面。不自动已入档。
- 待审列表对当前页建议理解边（只印证 / 增补）。人点了才写边。
- 开场工作记忆：已生效板 + 还算数的已入档；待审只报张数。
- 聊天用 `list_memory_cards` 列出待审；点头仍走 `nod_memory_card`。
- 摘录之后用 `open_node` 按 id 打开；有上限，`truncated` 表示档案更长，正文不裁。

## 决定不做

这些不是欠账。改闸时不要把它们当待办做进去。

| 项 | 原因 |
|---|---|
| 选择题硬拦开口 | 挡的是记账，不是说话。伪造语言闸会让人以为没开口就不算选择。 |
| 默认开 LLM 蒸馏 | 启发式短句可追溯。模型蒸馏当已入档会把猜测写成档案。 |
| 决策页改成选择题 | 页是台账。帮人选在聊天里走简报。 |
| 自动裁剪 / 遗忘会话 | 超长是档案装不下工作记忆，不是脏数据。 |

## 人要做

活窗口 `http://127.0.0.1:3080` 吃源码必须重启 DSH。源码测过不等于当前进程已加载。

## 改代码时

- 不要改 `search_text` 的匹配算法或桥合并。
- 不要把情景原文放进 `because`。
- 不要造假节点凑依据。
- 不要让自动抽取变成已生效。
- 抽卡不得截断会话正文。梳理手抽仍要 `nodded: true`。后台抽超长会话只出起草卡。
- 会话正文进图就能搜。实体/关系由工人按命中窗口补，不预抽、不占会话模型。
